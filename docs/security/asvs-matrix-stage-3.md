# ASVS 5.0 mapping: HTTP and API surface, transport security (Stage 3)

Standard: OWASP ASVS 5.0.0 (requirement text from the official `5.0.0` CSV). IDs are `v5.0.0-<chapter>.<section>.<requirement>`; text is shortened here, see the standard for the full wording.
This file covers V4 (API and web service) and V12 (secure communication), which the judge-node protocol and the first machine-facing routes made relevant. Earlier chapters are in `asvs-matrix.md` (V6 to V8) and `asvs-matrix-stage-2.md` (V1, V2, V5). V3 and V9 to V11, V13 to V17 remain open (F15).

**Summary.** 28 requirements: 7 met, 6 partial, 5 not met, 10 not applicable. By level: L1: Met 1/N/A 1/Not met 1/Partial 2, L2: Met 1/N/A 7/Not met 2/Partial 4, L3: Met 5/N/A 2/Not met 2.

Almost every partial and not-met row has one cause: **the edge (TLS termination, HTTP/2, certificates) is not built** because there is no deployment yet (cutlist F1). They must be re-checked when the edge exists; none can be signed off before.
