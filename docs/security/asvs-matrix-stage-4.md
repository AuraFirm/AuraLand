# ASVS 5.0 mapping: data protection and logging (Stage 4A)

Standard: OWASP ASVS 5.0.0 (requirement text from the official `5.0.0` CSV). IDs are `v5.0.0-<chapter>.<section>.<requirement>`; text is shortened here, see the standard for the full wording.
This file covers V14 (data protection) and V16 (security logging and error handling), which customers' data, download records and payment records made relevant. Earlier chapters are in `asvs-matrix.md` (V6 to V8), `asvs-matrix-stage-2.md` (V1, V2, V5) and `asvs-matrix-stage-3.md` (V4, V12). V3, V9 to V11, V13 and V15 and V17 remain open (F15).

**Summary.** 30 requirements: 13 met, 13 partial, 3 not met, 1 not applicable. By level: L1: Partial 2, L2: Met 10/Not met 3/Partial 10, L3: Met 3/N/A 1/Partial 1.

The not-met rows are documentation and deployment work (a classification with protection requirements, a logging inventory, log shipping), not missing controls in code. They are listed in `docs/cutlist.md` (F1, F40).
